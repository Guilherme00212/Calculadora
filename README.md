# Calculadora Web

Uma calculadora web moderna e responsiva, desenvolvida com HTML, CSS e JavaScript. O projeto realiza as quatro operações matemáticas básicas por meio de uma interface simples, elegante e fácil de usar.

## Funcionalidades

- Soma, subtração, multiplicação e divisão
- Exibição dos números e resultados no visor
- Botão para limpar a operação atual
- Tratamento de divisão por zero
- Suporte a operações consecutivas
- Interface responsiva para computadores e dispositivos móveis
- Efeitos visuais com transparência, desfoque e animações nos botões

## Tecnologias utilizadas

- HTML5 — estrutura da calculadora
- CSS3 — estilização, responsividade, Grid e efeitos visuais
- JavaScript — lógica das operações e interação com os botões
- Google Fonts — fonte Oswald

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em seu navegador.

Não é necessário instalar dependências ou configurar um servidor para executar o projeto.

## Como utilizar

1. Selecione o primeiro número.
2. Escolha uma operação matemática.
3. Selecione o segundo número.
4. Pressione `=` para visualizar o resultado.
5. Pressione `C` para limpar a calculadora e iniciar uma nova operação.

## Operações disponíveis

| Símbolo | Operação |
| :---: | --- |
| `+` | Adição |
| `−` | Subtração |
| `×` | Multiplicação |
| `÷` | Divisão |

## Responsividade

A interface utiliza CSS Grid, medidas flexíveis e media queries para se adaptar a diferentes tamanhos de tela.
